1. APRAKSTOŠĀ STATISTIKA
Aprakstošā statistika — vispārīgi Sīki aprakstīti centrālās tendences rādītāji (M, Mdn), izkliedes rādītāji (SD, IQR, Q1–Q3), asimetrijas/ekscesa rādītāji, minimums/maksimums. Atsevišķa apakšnodaļa ar piemērtabulām un teksta paraugiem. Minēts, ka norāda M, SD (vai Mdn, ja asimetrisks sadalījums). Paraugtabula 8. pielikumā. ✓ ✓
Kategorisko mainīgo biežumi un procenti Sīki aprakstīts nominālo un ordinālo mainīgo biežumu un procentu atspoguļošanas princips. Pieminēts kā daļa no izlases raksturojuma. ✓ ✓
Normalitātes testi Detalizēti aprakstīti Šapiro-Vilka (Shapiro-Wilk) un Kolmogorova-Smirnova (Kolmogorov-Smirnov) testi, Q-Q grafiki, histogrammas; pamato parametrisko/neparametrisko metožu izvēli. Minēts Kolmogorova–Smirnova tests pielikuma paraugtabulā (1. tabula). ✓ ✓
2. KORELĀCIJAS ANALĪZE
Pīrsona korelācijas koeficients (r) Sīks apraksts: lietošanas nosacījumi, virziena un stipruma interpretācija, korelāciju matrica, izkaisītās diagrammas. Minēts datu analīzes metodēs (4.8.4.) un atspoguļots 8. pielikumā ar paraugtabulu un grafikiem. ✓ ✓
Spīrmena rangu korelācija (rs) Detalizēts apraksts: nosacījumi, piemēri ar scatter plot vizualizāciju. Minēts datu analīzes metodēs kā neparametriska alternatīva. ✓ ✓
Biseriālā rangu korelācija (rb) Aprakstīta kā efekta lieluma rādītājs Manna-Vitneja U testam; minēta arī simbolu sarakstā. — ✓ —
3. DIVU GRUPU SALĪDZINĀŠANA
Stjudenta t-tests (t) Sīki aprakstīti pieņēmumi, efekta lielums (Kohēna d), kombinētas tabulas ar U-testu, teksta paraugi. Minēts 4.8.4. sadaļā, detalizēts 8. pielikumā ar paraugtabulu (5. tab.) un rezultātu aprakstu. ✓ ✓
Manna-Vitneja U tests (U) Sīki aprakstīts: nosacījumi, Mdn un IQR rādītāji, efekta lielums (r), kombinēšana ar t-testu vienā tabulā. Minēts 4.8.4. sadaļā, detalizēts 8. pielikumā ar paraugtabulu (6. tab.) un rezultātu aprakstu. ✓ ✓
Velča t-tests (Welch's t) Pieminēts kā t-testa modifikācija, kad dispersijas nav viendabīgas (Lēvena tests nav izpildīts). — ✓ —
Lēvena tests (Levene's test) Aprakstīts kā dispersijas viendabīguma pārbaudes rīks pirms t-testa. — ✓ —
4. VAIRĀKU GRUPU SALĪDZINĀŠANA (DISPERSIJU ANALĪZE)
Vienfaktora ANOVA (F) Sīks apraksts: pieņēmumi, F-koeficients, brīvības pakāpes, post-hoc testi (Šefē, Tjuki, Bonferroni), efekta lielums (η²), paraugtabulas. Detalizēts 8. pielikumā ar paraugtabulu (4. tab.), F, df, post-hoc (Scheffé) un η² aprakstu. ✓ ✓
Kruskala-Volisa H tests (H) Sīks apraksts: neparametriskais ANOVA analogs, post-hoc (Manna-Vitnija U ar Bonferroni korekciju), paraugtabulas. Minēts datu analīzes metodēs kā neparametriskais analogs. ✓ ✓
ANCOVA, divfaktoru ANOVA, atkārtoto mērījumu ANOVA Pieminētas kā papildu dispersijas analīzes varianti; dokumentā norādīts, ka to aprakstu jāmeklē APA7 vai citos avotos. — ✓ —
5. REGRESIJAS ANALĪZE
Vienkāršā lineārā regresija Aprakstīta kā viena neatkarīgā mainīgā variants lineārās regresijas ietvaros. Minēta kā regresijas analīzes veids datu apstrādes sadaļā. ✓ ✓
Multiplā regresija (Enter, soļu metode) Detalizēts apraksts: β, R², ΔR², F, t, p rādītāji; soļu (stepwise) metodes paraugtabulas. Detalizēts 8. pielikumā ar paraugtabulām (7. un 8. tab.) un rezultātu piemēriem. ✓ ✓
Mediācijas un moderācijas analīze Pieminēta kā papildu metode; norādīts, ka jāmeklē Hesa (Hayes, 2018) literatūrā. — ✓ —
Loģistiskā regresija Pieminēta kā viena no papildu regresijas metodēm. — ✓ —
6. FAKTORU ANALĪZE
Izpētošā faktoru analīze (EFA) Sīks apraksts: PAF, PCA metodes, rotācijas (Varimax, Oblimin, Promax), KMO, Bartleta tests, Kaizera kritērijs, faktoru matrica, komunalitātes, izskaidrotā dispersija, paraugtabulas. Pieminēta kā psihometrisko rādītāju analīzes metode (4.9. sadaļā un 8. pielikumā). ✓ ✓
Apstiprinošā faktoru analīze (CFA) Sīks apraksts: modeļu salīdzināšana (2-faktoru vs 3-faktoru), atbilstības indeksi (CFI, TLI, RMSEA, SRMR), χ², otrās kārtas faktoru analīze, DWLS metode. Pieminēta kā psihometrisko instrumentu validēšanas metode. ✓ ✓
7. PSIHOMETRISKO RĀDĪTĀJU ANALĪZE
Kronbaha alfa (α) — iekšējā saskaņotība Sīks apraksts: interpretācijas robežvērtības, atspoguļošana faktoru analīzes tabulās. Minēta kā galvenais iekšējās saskaņotības rādītājs (4.8.2., 4.9. sadaļās). ✓ ✓
Makdonalda omega (ω) Aprakstīta kā alternatīvs iekšējās saskaņotības rādītājs blakus Kronbaha alfai. — ✓ —
Pantu reakcijas (grūtības) indekss Sīks apraksts kā psihometrisko rādītāju absolūtais minimums instrumenta analīzē. — ✓ —
Diskriminācijas indekss (item-rest correlation) Sīks apraksts: interpretācija, robežvērtība (0,30), 95% ticamības intervāli. — ✓ —
8. METAANALĪZE UN SISTEMĀTISKAIS PĀRSKATS
Naratīvā sintēze — Aprakstīta kā kvalitatīvā sistemātiskā pārskata datu sintēzes metode (7.2.6. sadaļā). — ✓
Metaanalīze (fiksēto/variējošo efektu) — Aprakstīta kvantitatīvajā sistemātiskajā pārskatā (7.2.6. sadaļā), ieskaitot RevMan programmatūru. — ✓
Metaetnogrāfija un kvalitatīvā tematiskā sintēze — Aprakstītas kvalitatīvajā sistemātiskajā pārskatā (7.2.6. sadaļā). — ✓
Jauktā dizaina sintēze (nošķirtā, integrētā, eventuālā, reālistiskā) — Detalizēti aprakstītas jaukta dizaina sistemātiskajā pārskatā (7.2.6. sadaļā). — ✓
9. PERSPEKTĪVĀS / MŪSDIENU METODES (minētas kā nākamais solis)
SEM (Strukturālā vienādojuma modelēšana) Pieminēta kā mūsdienu pētniecības metode publicēšanai (nodaļas noslēgumā). — ✓ —
Tīklu analīze, Bayesian ANOVA/t-tests, mašīnmācīšanās Pieminētas kā aktuālās metodes augstākā izglītības līmenī un publikācijām. — ✓ —
Daļējo mazāko kvadrātu korelācija/regresija (PLS), kanoniskā korelācija, ANOM, Mixed Logit Models Pieminētas kā perspektīvās metodes publikācijām. — ✓ —
